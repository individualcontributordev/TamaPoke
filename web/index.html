🍃 TamaPoke Gentle

Firmware: 1.37.0-gentle · Gen 1–3

A relaxed TamaPoke for small trainers, for the Waveshare ESP32-S3-Touch-AMOLED-1.75. All 386 Pokémon from Kanto, Johto and Hoenn.

What's different
  • Your Pokémon never leaves: no farewell, no runaway, no release.
  • Needs drop slowly (about 6 h from full to hungry, was ~1.5 h), so a care break of 5–6 hours is fine.

⚠️ Use desktop Chrome or Edge. This browser does not support Web Serial.

1Flash firmware 1.37.0-gentle

Connect the board by USB, press install and select its serial port.

Browser not supported (use Chrome/Edge). Needs HTTPS or localhost.

Updating? The dialog shows an Erase device checkbox. Leave it unchecked: your Pokémon and progress stay on the board. Then you are done; skip step 2. Download a backup (below) first if the save matters.

2Install all 386 sprites — new or empty microSD only

Insert a microSD card. Close the flashing dialog, connect the board again, then press the single install button. It sends the Kanto/Johto package first and the Hoenn package second.

Do not unplug the board or remove the microSD during transfer. A card that already holds the Gen 3 sprites needs no second transfer.
